# CIVE 202 – Project #3: Transportation Data Visualization

## Client
Federal Highway Administration (FHWA)

## Project Overview
This project analyzes transportation data using two datasets:
- National Household Travel Survey (NHTS)
- Next Generation Simulation (NGSIM)

The goal is to visualize travel behavior, analyze driving patterns, and simulate vehicle behavior using the Intelligent Driver Model (IDM).

## Contents
- Data folder contains both datasets used in the analysis
- Notebook folder contains the full Python analysis
- Report folder contains the written report and scope of work
- Code folder contains annotated Python code

## How to Run
1. Open the Jupyter Notebook:
   `Project3_Visualization.ipynb`
2. Run all cells in order
3. Ensure the CSV files are located in the same folder or correct path

## Key Features
- Bar chart of vehicle type
- Histogram of vehicle age
- Boxplot comparing fuel type and age
- Time-series analysis of vehicle trajectories
- IDM simulation of follower behavior
